One line of weather, 140 characters at most, for a city that does not exist — written to make a bored commuter smile on the way to work.

Entry (103 characters):

> Good morning, Drizzlewick: light umbrella rain, heavy sighs, and a 90% chance your bus is already gone.

## How it works

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
